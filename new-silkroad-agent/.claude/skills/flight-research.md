# ✈️ 航空ルート自己調査スキル

ユーザーが国際線（特に仙台↔台北）の航空ルートをリアルタイムで調査・比較するための統合ガイド＋ツール。

## 📌 このスキルが提供するもの

### 1️⃣ **OTA検索ガイド** (Markdown)
- 推奨OTA（駅探・NAVITIME等）への直接リンク集
- 段階的な検索手順（Step-by-Step）
- 検索のコツ・よくある失敗例

### 2️⃣ **インタラクティブなデータ収集ツール** (HTML)
- 直行便・乗り継ぎ便のデータ入力フォーム
- 自動計算・統計分析
- 自動ランキング生成（コスパ/時間効率/バランス）

---

## 🎯 使い方

### 基本的な流れ

```
Step 1: OTAガイドを参照
   ↓ (OTAで実際にデータ取得)
Step 2: データ収集ツールに入力
   ↓ (自動計算)
Step 3: ランキング・比較表を確認
   ↓
最適なルートを発見
```

### コマンド例

```bash
/flight-research 仙台 台北              # 仙台↔台北の調査ガイド表示
/flight-research 仙台 台北 --tool      # データ収集ツール表示
/flight-research --comparison          # 過去に調査した結果の比較
```

## 📊 データ収集ツール機能

### 入力フォーム
- ✅ 直行便（往路/帰路）
- ✅ 乗り継ぎ便（複数ハブ対応）
- ✅ 時刻・料金・機材情報

### 自動計算
- 📈 統計情報（最安値・最高値・平均）
- 🕐 総移動時間・乗り継ぎ時間
- 💰 往復総料金

### 自動ランキング
- 🏆 **コスパ重視**: 料金順
- ⚡ **時間効率**: 所要時間短順
- ⭐ **バランス型**: スコア式（価格 × 0.5 + 時間効率 × 0.5）

## 📝 調査手順（詳細版）

### Phase 1: 直行便情報取得（1時間）

```
1. OTAで検索
   ├─ 複数の日付を試す
   ├─ 全航空会社をチェック
   └─ 往路・帰路を記録

2. 料金情報を確認
   ├─ 最安値・標準料金
   ├─ セール情報
   └─ キャンペーン割引
```

### Phase 2: 乗り継ぎパターン探索（1-2時間）

```
1. Google Flights / Trip.com で乗り継ぎ自動表示
   ├─ 複数ハブを試す
   └─ 時間・料金を記録

2. 国内線 → 国際線を個別検索
   ├─ 名古屋経由
   ├─ 福岡経由
   ├─ 沖縄経由
   └─ 関西経由
```

### Phase 3: データ入力・分析（30分）

```
1. ツールにデータ入力
2. 自動で統計・ランキング生成
3. 最適ルートを選定
```

---

## 💡 検索のコツ

### ✅ 効果的な方法
- 複数日付の試行（月初/月末、平日/週末）
- 複数ハブの試行
- 柔軟性の確認（±1日で料金変動）
- 往路・帰路を分けて検索

### ❌ よくある失敗
- 🚫 1つの日付だけで判断
- 🚫 乗り継ぎ時間を過小評価
- 🚫 松山空港を見落とし
- 🚫 OTA表示料金を確定と勘違い

## 📌 注記

- **リアルタイム対応**: OTAのデータは常に変動。月1回は更新推奨
- **往復セット検索**: 個別に検索して組み合わせる方が安い場合あり
- **乗り継ぎ時間**: 国内→国際は120-150分を想定
- **時差**: 台北は日本より1時間遅い（UTC+8）
