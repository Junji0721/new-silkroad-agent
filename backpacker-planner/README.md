# 🧳 Backpacker Planner

仙台空港（SDJ）をハブとした、バックパッカー向け海外周遊ルート検索・比較プラットフォーム。

## 🎯 目的

- 仙台空港からの最適な航空ルートを検索・比較
- 直行便と乗り継ぎ便のコスト・時間を客観的に分析
- 長期バックパッカー向けの複数ルートシミュレーション

## 🗂️ ディレクトリ構成

```
backpacker-planner/
├── src/              # スクリプト・データ処理ロジック
├── data/
│   ├── routes/       # ルート定義・管理
│   ├── flights/      # フライト検索結果
│   └── comparisons/  # ルート比較・分析データ
├── content/          # 旅程表・企画案
└── docs/             # ドキュメント
```

## 📋 使用可能なツール

- **WebSearch / WebFetch**: 航空会社の時刻表・料金情報をリアルタイム検索
- **JSON / CSV**: データの構造化・管理
- **Bash / Python**: スクリプト化・自動化

## 🌍 マイル活用戦略（高度な活用法）

ANAマイルをお得に使うために、以下の概念を組み合わせた複数ルート提案を実装：

### 📍 発券戦略の種類

| 戦略 | 説明 | お得度 | 活用シーン |
|------|------|--------|----------|
| **スルー発券** | A→B→C を一つの航空券で発券 | ⭐⭐⭐⭐⭐ | 周遊時の最安 |
| **経由（レイオーバー）** | B地点で短時間（12-24h）の乗り継ぎ | ⭐⭐⭐⭐ | 複数都市訪問 |
| **ストップオーバー** | B地点で中程度の滞在（24h-数日） | ⭐⭐⭐⭐ | 経由地での観光 |
| **オープンジョー** | 往路A→B、帰路C→A（異なる都市） | ⭐⭐⭐⭐⭐ | 周遊ルート最適 |
| **以遠権フライト** | パートナー航空で目的地以遠へ | ⭐⭐⭐ | エリア拡張 |
| **MCT考慮** | 最小乗り継ぎ時間を計算した最適発券 | ⭐⭐⭐ | 実現性確保 |
| **サーフェス（陸路）** | 航空便を飛ばし陸路で移動 | ⭐⭐⭐⭐ | 連続特典活用 |

### 📊 マイル効率の指標

| 戦略 | マイル/¥換算 | 効率度 | 難度 |
|------|-------------|--------|------|
| 単純往復（直行） | 1マイル = 1.5円 | ⭐⭐⭐ | 簡単 |
| スルー発券 | 1マイル = 2.0-2.5円 | ⭐⭐⭐⭐⭐ | やや複雑 |
| オープンジョー | 1マイル = 2.0-2.5円 | ⭐⭐⭐⭐⭐ | 複雑 |
| 複合戦略 | 1マイル = 2.5-3.0円 | ⭐⭐⭐⭐⭐ | 非常に複雑 |

### ⚠️ マイル発券の注意点

- **事前予約**: 特典航空券は空きが限定的。2-3ヶ月前の予約推奨
- **MCT確認**: 乗り継ぎ便は最小乗り継ぎ時間（MCT）を確認必須
- **規定確認**: 各航空会社の「ストップオーバー」「レイオーバー」規定を確認
- **パートナー航空**: ANA マイルの場合、スターアライアンス加盟航空利用可
- **往復と片道**: 往復より片道 × 2 の方が安い場合も（要確認）
- **サーフェス利用**: 最大8時間の陸路移動を無料で追加可能（航空会社依存）
