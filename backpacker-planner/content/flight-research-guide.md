# 🔍 仙台↔台北 航空ルート自己調査ガイド

**目的**: OTA（Online Travel Agency）を活用して、リアルタイムの全フライト情報・料金を自分で調査し、最適なルートを発見する。

---

## 📌 調査に必要な情報

### 1️⃣ **直行便情報**
- 出発時刻 / 到着時刻
- 航空会社 / 便名
- 機材 / 所要時間
- 料金（片道・往復）
- 運航日（曜日パターン）

### 2️⃣ **乗り継ぎパターン**
- 第1便: 仙台 → ハブ（名古屋/福岡/沖縄/関西）
- 乗り継ぎ時間 / ターミナル情報
- 第2便: ハブ → 台北（桃園/松山）
- トータル時間 / トータル料金

### 3️⃣ **空港バリエーション**
- 台北桃園国際空港（TPE）
- 台北松山空港（TSA）

## 📝 調査手順（Step-by-Step）

### Phase 1: 直行便の全情報取得（1時間）

```
Step 1: 駅探で仙台→台北（桃園）を検索
  ├─ 複数の日付を試す（平日/週末、月初/月末等）
  ├─ 全ての便の「出発時刻/到着時刻/料金」を記録
  └─ 航空会社別にグループ化

Step 2: 駅探で台北（桃園）→仙台を検索
  ├─ 同様に複数日付を試す
  ├─ 帰路の全情報を記録
  └─ 往復のセット料金がないか確認

Step 3: 松山空港ルートも確認
  ├─ 駅探で仙台↔台北松山を検索
  ├─ 松山発着便の有無を確認
  └─ 料金・時刻を記録

Step 4: 各航空会社の公式サイトで確認
  ├─ EVA Air / China Airlines / Starlux / Tiger Air
  ├─ 正確な料金・キャンペーンを確認
  └─ 不一致があれば公式情報を採用
```

### Phase 2: 乗り継ぎパターンの探索（1-2時間）

```
Step 1: Google Flights / Trip.com で乗り継ぎオプション表示
  ├─ 「ストップを許可」にチェック
  ├─ 「複数ルート表示」にする
  └─ 乗り継ぎの時間・料金を記録

Step 2: 駅探で国内線 → 国際線を個別検索
  
  【名古屋経由の場合】
  ├─ ANA 仙台→名古屋（時刻表を記録）
  ├─ 乗り継ぎ時間を計算（120-150分推奨）
  └─ ANA/他社 名古屋→台北（時刻表を記録）
  
  【福岡経由の場合】
  ├─ ANA/JAL 仙台→福岡（複数便を記録）
  ├─ 乗り継ぎ時間を計算（90-120分）
  └─ EVA/他社 福岡→台北（時刻表を記録）
  
  【沖縄経由の場合】
  ├─ ANA/JAL 仙台→沖縄（複数便を記録）
  ├─ 乗り継ぎ時間を計算（90-120分）
  └─ EVA/他社 沖縄→台北（時刻表を記録）
  
  【関西経由の場合】
  ├─ ANA/IBEX 仙台→関西（複数便を記録）
  ├─ 乗り継ぎ時間を計算（120-150分）
  └─ CA/EVA 関西→台北（時刻表を記録）

Step 3: 乗り継ぎの現実性を確認
  ├─ 最小接続時間：国内→国際 = 120-150分
  ├─ 遅延対応：プラス30分の余裕を想定
  └─ 荷物の引き取り要否を確認
```

### Phase 3: データ整理＆比較（30分）

```
Step 1: 収集データを表形式に整理
  ├─ テンプレート（後述）を使用
  ├─ 直行便 / 乗り継ぎ別に分類
  └─ 正規化（時間・コスト・利便性）

Step 2: ランキング付け
  ├─ 「快適性重視」トップ3
  ├─ 「コスパ重視」トップ3
  ├─ 「時間効率」トップ3
  └─ 「柔軟性」トップ3
```

## 💡 検索のコツ

### ✅ 効果的な検索方法

1. **複数日付の試行** 
   - 月曜日 vs 土曜日
   - 月初 vs 月末
   - ハイシーズン vs オフシーズン

2. **複数ハブの試行**
   - 名古屋・福岡・沖縄・関西
   - 「所要時間」vs「料金」の trade-off を把握

3. **片道 vs 往復**
   - 往復割引がないか確認
   - 異なる航空会社の組み合わせも試す

4. **柔軟性の確認**
   - 日程を±1日ズラして料金変動を確認
   - 時間帯（朝/昼/夜）で料金差を確認

### ❌ よくある失敗

- 🚫 1つの日付・ハブだけで判断
- 🚫 乗り継ぎ時間を過小評価（実際は120分必要）
- 🚫 OTA表示料金を確定と勘違い（変動する）
- 🚫 台北松山空港の便を見落とし

## 🎯 調査後のアウトプット

調査が完了したら、以下をまとめます：

1. **直行便ランキング**
   - Top 5（料金順）
   - 出発時刻別オプション

2. **乗り継ぎランキング**
   - ハブ別（名古屋/福岡/沖縄/関西）
   - パターン別（朝/昼/夜）

3. **往復総額比較**
   - 直行便（往復）
   - 最安乗り継ぎ（往復）

4. **シナリオ別おすすめ**
   - 快適性重視
   - コスパ重視
