# 🧳 backpacker-planner プロジェクト指示書

## プロジェクト概要
仙台空港（SDJ）をハブとした、バックパッカー向け海外周遊ルート検索・比較プラットフォーム。

## 目的
- 最適な航空ルート（直行便・乗り継ぎ）を検索・比較
- コスト効率と移動時間をバランスさせた提案
- 長期バックパッカー向けの複数ルートシミュレーション

## ディレクトリ構成
```
backpacker-planner/
├── src/                    # スクリプト・ロジック
├── data/
│   ├── routes/            # ルート定義
│   ├── flights/           # フライト情報（検索結果）
│   └── comparisons/       # 比較データ・分析
├── content/               # 旅程表・企画案
└── docs/                  # ドキュメント
```

## 作業ルール
1. すべてのコミュニケーションは日本語
2. 航空券検索は WebSearch / WebFetch を活用（リアルタイム情報）
3. データは JSON / CSV で構造化
4. 個人情報・APIキーは `.env` で管理（`.gitignore` に記載）

## 現在のマイルストーン
- M1: 仙台（SDJ）→ 福岡（FUK）の直行便/乗り継ぎ比較表作成
- M2: 海外主要路線（東アジア・東南アジア）への拡張
- M3: バックパッカー向け複数都市周遊ルート自動提案
